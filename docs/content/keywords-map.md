## How these 100 keywords were chosen

1. **73 seed searches** (every service, item, area, "free", "price", "municipality", "how to", donation and move-out variations) were run through **Google Autocomplete with UAE location (`gl=ae`)**. Autocomplete only suggests queries that real people search frequently, so it's a reliable *relative* popularity signal.
2. That produced **~300 real query suggestions**. Off-topic ones (property sales, jobs, other cities) were removed, leaving 109 relevant candidates.
3. The **9 weakest** (never suggested, or global rather than Dubai-specific) were dropped, leaving **100**.
4. Each keyword was given an intent, a single target URL (no two pages compete for the same term) and a status.

### Demand signal (legend)

| Signal | Meaning |
| --- | --- |
| 🟢 **Strong** | Google suggested it under **3+ different seed searches**, or under 2 seeds as the **first** suggestion. High, broad demand. |
| 🟡 **Good** | Suggested under 2 seeds, or as one of the **top 3** suggestions for a seed. Solid demand. |
| ⚪ **Long-tail** | Suggested once, lower in the list. Smaller but very specific — often converts well. |

**Seen** = number of seed searches where Google suggested this exact query.

> ⚠️ **No exact monthly volumes.** Autocomplete shows *which* queries are popular, not *how many* searches they get. Verify volumes in **Google Keyword Planner** (location: Dubai) and, once traffic builds, in **Search Console → Performance → Queries**. Add a "Volume" column when you have real data — don't estimate.

### Status (legend)

| Status | Meaning |
| --- | --- |
| **Live** | A published page targets it. *(primary)* = the page's main keyword; *(secondary)* = supporting term on that page. |
| **Planned** | Will be covered by a planned article (see section 3). |
| **Gap** | We don't offer this service yet — needs a client decision before any page is created. |

### What the data says

- **"Free" and "municipality" are the biggest untapped cluster (20 keywords).** People strongly search for free furniture disposal and Dubai Municipality's bulky-waste service. One honest, thorough guide can rank for all of them — and explain why residents of development zones and free zones (where the free service isn't available) need a private option.
- **"How to dispose … in Dubai" is high-intent research.** `how to dispose old furniture in dubai` appeared under 6 seeds — one of the strongest signals in the whole set. It's already the primary keyword of a live article.
- **Price searches are popular but need real prices.** Four price/cost keywords are ready for a cost guide as soon as the client confirms price ranges.
- **Donation is its own cluster (7 keywords).** Worth a dedicated guide — every organisation named must be verified first.
- **Areas:** Google already suggests "junk removal" for Dubai Hills, Dubai Marina, JVC, Palm Jumeirah, Arabian Ranches (1 and 2) and Business Bay — all have live area pages.

## 4. How to use this map

1. **Before writing anything**, find the keyword here. If it's already *Live*, improve that page instead of creating a new one.
2. **One primary keyword per page.** Secondary keywords from the same cluster go in H2s, FAQs and body copy naturally.
3. **Put the primary keyword** in the `<title>`, H1, URL slug and first 100 words (see [`content-rules.md`](./content-rules.md)).
4. **Set `keyword`** in the post's data file (`src/data/posts/*.ts`) to the primary keyword from this map.
5. **After publishing**, change the status here to *Live* and request indexing in Search Console.
6. **Every month**, check Search Console queries: new terms that appear go into this map and onto the page that already ranks for them.
